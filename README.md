# Brainwave

A party game of reading each other's minds. A Psychic sees a hidden target on a dial between two extremes, like Cold and Hot, and gives a one-word clue. Their teammates turn the needle to where they think the target is. The closer they land, the more they score.

It is a single static page (`index.html`) with 177 built-in spectrum cards and an option to add your own. Play in teams (4+ players, first to 10) or in 2-player co-op mode (work together over 7 cards, with a bonus card for each bullseye). Difficulty picks the card set: Easy (concrete scales like Cold / Hot), Normal (taste and opinion like Underrated / Overrated), Hard (abstract, debatable scales like Vice / Virtue) or Mixed.

Open `index.html` in a browser, or serve the repo with GitHub Pages. Play it pass-and-play on one device, or share your screen on a video call. Only the Psychic should look while the target is shown.
